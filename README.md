# Androkiosk

Free, open-sourced app for displaying content on Android kiosk displays.

## Build

Requires JDK 17 or newer and the Android SDK. Point the build at your SDK with `ANDROID_HOME` or a `local.properties` containing `sdk.dir`.

```
./gradlew assembleDebug
./gradlew installDebug
```
